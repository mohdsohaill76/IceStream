# IceStream Documentation

## Responsibility
The `docs` directory contains technical specifications, architectural diagrams, API schemas, and data contract definitions for the IceStream system.

## Planned Documentation
- `architecture/`: High-level system design, data flow diagrams, and component interactions
- `api/`: REST and WebSocket API specifications
- `data-contracts/`: Schema definitions and contracts for Kafka topics, Iceberg tables, and event models
